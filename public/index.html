Confluence Trust Auditor

Confluence records when a page was edited. It has no record of whether anyone has checked it's still true.

This scans a space for two things nobody currently tracks: pages that have sat untouched long enough that nobody can vouch for them, and pages holding passwords, salary figures, or "confidential" notes that probably shouldn't be readable by Rovo or any other AI feature with access to the space.

How it works

What actually happens during a scan

1
Pull every page in a space
Reads title, last-edit timestamp, and labels through Confluence's own REST API using an API token, nothing beyond normal read access.
2
Score staleness
A page is flagged only if it is both old (past a day threshold you set) and has no reviewed label, so a page someone recently verified is never falsely flagged.
3
Scan content for exposure risk
Pattern-matches page text against secrets, salary figures, and confidential markers, so admins know what an AI feature reading the space could surface.
4
Write one report
Everything lands in a single HTML file. A human decides what to do with each flag; nothing is auto-deleted or auto-restricted.

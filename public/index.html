    HOW IT WORKS

    What happens during a real scan

    1

    Read the space

    Pulls titles, last-edit dates and labels through Confluence's REST API with an API token.

    2

    Score staleness

    Flags a page only if it is old and has no review label, so verified pages are never flagged.

    3

    Check exposure

    Pattern-matches for secrets, salary figures and confidential markers an AI feature could surface.

    4

    Report, don't act

    Writes one HTML report. A person decides what to fix. Nothing is deleted or restricted automatically.

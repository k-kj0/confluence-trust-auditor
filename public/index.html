Confluence Trust Auditor

Confluence shows you when a page was last edited, not whether anyone has checked it's still accurate. This tool scans a space for pages that have gone untouched for a long time and for pages that mention things like passwords, salary numbers, or "confidential" that probably shouldn't be exposed to AI features reading across a space.

This demo runs against a small set of sample pages, nothing real. You can see the tool's actual output below.
